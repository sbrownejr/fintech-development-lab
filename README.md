# FinTech Development Lab
A hands-on learning project focused on Python, AI agents, blockchain, financial technology, and software development.
## Shawn's FinTech AI Assistant
This repository includes a Python-based FinTech AI Assistant developed through a series of incremental versions. 
### Current Capabilities
- Interactive AI conversation loop
- Finance and blockchain question support
- Conversation memory during a session
- Saved conversation history
- Built-in help commands
- Assistant system status checks
- Approved-workspace file access
- Safe file listing and reading
- Text document analysis
- Conversation memory clearing
- Command type suggestion saving
- Safe exit and automatic conversation saving
### Safety Design
The assistant uses an approved workspace for file access rather than unrestricted access to the computer. This project demonstrates an early implementation of least-privilege design and user-controlled AI tools.
### Built=In Commands
- 'help' - Show available commands
- 'status' - Display assistant and workspace status
- 'files' - List files in the approved workspace
- 'read<filename>' - Read an approved workspace file
- 'analyze <filename>' - Analyze an approved text document
- 'clear' - Clear current conversation memory
- 'exit' - Save the conversation and close the assistant
